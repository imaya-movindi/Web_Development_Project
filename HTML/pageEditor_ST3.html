Teams Page

Technical Description

Introduction

The team page is designed to showcase the members of the team, their roles, and contributions to the project. It features a visually appealing layout with interactive elements that allow users to hover or click on team members to view more details. The page is styled to be modern and responsive, ensuring a seamless experience across different devices.

HTML Structure

  1. Body
    • The .team_container class div acts as the main wrapper, ensuring the team members are displayed in a grid-like format.
    • Each .team_member class div contains an image of the team member and a .details div that displays additional information when hovered or clicked.
    • The .footer section contains the footer content, including links and social media icons.

CSS Styling

  1. Background and Layout
    • The background is styled with a gradient using background: linear-gradient(to right, lightblue, grey); to create a visually appealing backdrop.
    • The .team_container class ensures the team members are centered and spaced evenly.
    • The .team_member class is styled with a hover effect that scales the image and displays the details section.
  2. Team Member Cards
    • Each team member card is styled with a circular image using border-radius: 50%;.
    • The .details section is hidden by default and displayed when the user hovers or clicks on a team member. It is styled with a semi-transparent background and white text for readability.
  3. Footer Styling
    • The footer is styled with a dark background and white text, ensuring it stands out from the rest of the page.
    • Social media icons are styled with hover effects to make them interactive.

JavaScript Functionality

  1. Interactive Details
    • JavaScript is used to toggle the visibility of the .details section when a team member is clicked. This is achieved by adding an event listener to each .team_member element that toggles the show class on the .details section.

Conclusion

The team page enhances user experience by providing an interactive and visually appealing way to learn about the team members. The use of hover effects, circular images, and hidden details sections adds an interactive element, making the page more engaging.

Feedback Form

Technical Description

Introduction

The feedback page is designed to collect user feedback on their experience with the website. It includes a form with various input fields, radio buttons for quick responses, and a textarea for detailed suggestions. The page is styled to be visually appealing and user-friendly, ensuring a seamless experience for users to provide their feedback.

HTML Structure

The HTML document is designed in a structured manner to enhance accessibility and clarity.

  1. Meta tags
    • <meta name="viewport" content="width=device-width, initial-scale=1.0">
    • Responsiveness on various devices has been ensured by this.
  2. Body
    • The .container class div acts as the main wrapper, ensuring the form is centered and easy to navigate.
    • The .user-details class div contains the input fields for user information and feedback.
    • The .visiting class div contains radio buttons for quick responses.
    • The .button class div contains the submit button.

CSS Styling

  1. Background and Layout
    • The background is styled with a gradient using background: linear-gradient(135deg, lightblue, grey); to create a visually appealing backdrop.
    • The .container class ensures the form is centered and has a maximum width for better readability.
    • The form elements are styled with padding, borders, and rounded corners to enhance the user experience.
  2. Input Fields and Textarea
    • Input fields and textarea are styled with consistent height and width, ensuring uniformity across the form.
    • The textarea is disabled by default and only enabled when the user selects "No" for the question about the website's ease of navigation.
  3. Radio Buttons
    • Custom radio buttons are created using the .dot class, which uses border-radius: 50%; to create circular buttons.
    • The radio buttons change color when selected, providing visual feedback to the user.
  4. Typography & Readability
    • The font-family "Poppins", sans-serif; is used for clarity and readability.
    • Headings and labels are styled to ensure proper hierarchy and structure.
  5. Button Styling
    • The submit button is styled with a gradient background and hover effect to make it visually appealing and interactive.

JavaScript Functionality

  1. Form Validation
    • The form includes validation for required fields, ensuring that users provide necessary information before submission.
    • Email validation is implemented using a regular expression to ensure the email format is correct.
    • The suggestion box is enabled only when the user selects "No" for the question about the website's ease of navigation.
  2. Event Listeners
    • Event listeners are added to the radio buttons to enable or disable the suggestion box based on user input.
    • The form submission is handled with an event listener that validates the form and displays a success message upon successful submission.

Conclusion

The feedback page enhances user experience by providing a simple and intuitive way for users to share their feedback. The use of custom radio buttons, consistent styling, and form validation ensures that the page is both visually appealing and functional. The automatic enabling of the suggestion box based on user input adds an interactive element, making the feedback process more engaging.

Content Page

Technical Description

Introduction

The webpage titled "Quality Education: Building Sustainable Societies" is an informational content page focusing on the societal and economic impacts of education. The structure is clean and user-friendly, with a responsive layout that adapts well across different screen sizes. The design incorporates interactive elements such as hover effects and a "Go to top" button to enhance usability.

HTML Structure

  1. Header & Title
    • The <h1> tag prominently displays the main title of the page, centered and styled for visual emphasis.
  2. Internal Navigation
    • A navigation bar implemented using a <div> with class internal-nav contains anchor links to internal sections of the page.
    • Each link is styled as a button and scrolls to the respective section, improving in-page navigation.
  3. Main Content
    • The <main> container holds multiple <section> elements, each styled with the card and secion_one classes.
    • Each section includes a heading (<h2>), a paragraph (<p class="p">), and an associated image representing the topic.
    • The layout uses a content-row flex container to position text and images side-by-side responsively.
  4. Go-to-top Button
    • A fixed-position anchor link at the bottom right corner provides a quick scroll to the top of the page.

CSS Styling

  1. Layout and Theme
    • The .profile-container class ensures the page content is centered and padded, with a soft background tone (although the color value f appears to be a typo and should be corrected).
  2. Navigation Bar
    • Styled with a navy background and white text for contrast, the internal nav bar appears as pill-like buttons with hover effects that enhance accessibility and user feedback.
  3. Cards
    • Each card features rounded corners, a light blue background (#cae3ff), and a drop shadow for depth.
    • Cards have a hover animation defined with a transform transition, although the property value is incomplete (transform: translateY();).
  4. Typography & Colors
    • Headings and text use navy and dark blue tones to ensure readability and thematic consistency.

Accessibility Overview

  1. Semantic HTML: Proper HTML5 elements such as <main>, <section>, <h1>, <h2>, <p>, and <a> are used to structure content meaningfully.
  2. Descriptive Alt Texts: All images include alt attributes, helping screen readers convey visual context to users with vision impairments.
  3. Color Contrast: The color choices (e.g., navy text on light backgrounds) offer sufficient contrast, supporting readability for users with low vision.
  4. Keyboard Navigation: All interactive elements, such as links and the “Go-top” button, are keyboard-accessible.
  5. Responsive Design: Flexbox (.content-row) and relative units ensure the layout adjusts to various screen sizes, aiding users on different devices.
  6. Fixed Navigation Support: The go-to-top button stays visible as users scroll, improving navigation without excessive movement.
  7. Areas for Improvement:
    • Fix the typo in background-color: f; — replace with a valid color like #ffffff.
    • Complete the hover animation value in transform: translateY(); — for example, use translateY(-5px).
